### 🔭 What I'm exploring now

I'm currently studying and experimenting with **Smart Cities and Intelligent Transportation Systems**.

One question particularly interests me:

> **What if the people using a transportation system were not just passengers, but the central source of information for continuously improving the service?**

I'm exploring how **Data Science, Big Data, Software Engineering, Gamification and Artificial Intelligence** can work together to create systems that better understand the needs of the population and adapt to them.

This is where several of my interests converge:

### 🤖 Software development in the AI era

I still write code.

I just don't think writing code is the whole job anymore.

AI is changing the way software is developed. That makes the questions behind the code increasingly important:

**What should we build?**
**Why should we build it?**
**Who are we building it for?**
**What problem are we actually solving?**

I'm interested in using AI not only as a coding assistant, but as another tool for **understanding problems, exploring possibilities and building better solutions.**
